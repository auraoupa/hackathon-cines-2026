# hackathon-cines-2026

This repository lists all the material that has been prepared for 2026 CINES GPU Hackathon

 - First, we have the MCMC sampler in Sesam/EnsDAM :
     - Preliminary short tests (with simplified codes): https://github.com/brankart/sesam/tree/master/build/Test_GPU
     - Compilation of Ensdam on adastra: https://github.com/brankart/ensdam/blob/master/tools/install_gpu.bash
     - Compilation of Sesam on adastra: https://github.com/brankart/sesam/blob/master/build/install_gpu.bash
     - Intermediate test case in the 'Posydonie' directory (in HOMEDIR and WORKDIR of jmbrankart)
 - Then, some tests on a particular [cdftool](https://github.com/meom-group/CDFTOOLS) : https://github.com/aureliealbertmeom/TEST_CDFMOC_GPU/tree/main
 - Last, the deployment of [Basilisk model](https://basilisk.fr/) on AMD GPU could be tested
